# Open-API Specs

[![license](https://img.shields.io/github/license/Re4DE/open-api?style=flat-square&logo=apache)](https://www.apache.org/licenses/LICENSE-2.0)

---

The `OpenAPI` specs in this repository are autogenerated by `GitHub Actions` from the `EDCs` and `Re4DE` repositories and published via `GitHub Pages` with `Swagger UI`.

The generated API specs support the different versions of the `EDCs` and `Re4DE`; you can change the version and the API via a dropdown in the upper-right corner. 

Available at: https://re4de.github.io/open-api/
